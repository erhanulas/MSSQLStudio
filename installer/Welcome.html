MSSQL Studio

Native SQL Server çalışma alanı.

Uygulama Mac’in ana Uygulamalar (/Applications) klasörüne kurulur. Kayıtlı bağlantılar, Keychain parolaları, tercihler ve yerel nesne indeksleri korunur.

Kuruluma devam etmeden önce açık sorgularınızı kaydedip MSSQL Studio’yu kapatın.

macOS 27 ve Apple Silicon gerekir. Microsoft ODBC Driver 18, unixODBC ve OpenSSL 3 mevcut yerel kurulumdan kullanılır; bu paket sürücü kurmaz.
